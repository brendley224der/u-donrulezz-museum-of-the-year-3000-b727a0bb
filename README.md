A deterministic program (pure Python stdlib) that writes one museum label for the year 3000: the label a future museum puts beside an airport security tray from 2024, misread as a ritual basin in which travellers placed their shoes, belts and dignity before being scanned for purity.

## Run it

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (override with `OUTPUT_PATH`).
